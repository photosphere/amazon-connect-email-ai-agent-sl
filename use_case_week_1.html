sl-email-ai-triage: The triage entry point, invoked synchronously by the flow: reads the email (subject, sender/recipients, body and attachment list); applies safety guards (SES spam/virus verdict, auto-reply/bounce loop protection, chat-origin email, phishing); decides NEW vs REPLY (Connect thread link, [Ref: EA-xxxx] case token, Re: prefix + open case with the same subject, quoted history); runs a fast Claude Haiku classification (language, intent dcodes, hotel, sentiment, complaint, human request); creates/updates the case, starts the agent asynchronously and returns routing attributes. The flow then loops Wait → action=poll to fetch the agent result from it.

sl-email-ai-agent: The reply engine, invoked asynchronously by triage (InvocationType=Event): using the case history (multi-turn context), the email and its attachments, it runs the Claude (Bedrock Converse) tool-use loop (this week: knowledge-base search search_knowledge_base and similar) → drafts the answer via submit_reply → runs a grounding check against the retrieved evidence → composes the email from the official templates (greeting, signature) → writes the result (AUTO_SEND / HUMAN_REVIEW / ESCALATE, AI draft and summary) for the flow to poll, plus a per-email report row. Scenarios not enabled this week are forced to ESCALATE for a human.

3.4 环境注意事项（由代码逻辑推出）3.4 Environment notes (derived from the code logic)

  • 回环保护：同一发件地址在 1 小时内已收到 5 封 AI 自动回复（AUTO_SEND）后，后续邮件转人工（TC-W1-014）。测试邮箱 A 在 S1 系列中最多产生 5 封 AUTO_SEND，之后 1 小时内不要再用 A 执行其他用例。Mail-loop protection: once the same sender address has received 5 AI auto-replies (AUTO_SEND) within 1 hour, subsequent emails are escalated to a human agent (TC-W1-014). Test mailbox A produces at most 5 AUTO_SEND replies in the S1 series; do not use A for other cases during the following hour.
  • 若部署时设置了 POC_NOW，所有 AI 回复时间戳都等于固定的 POC_NOW，“最近 1 小时”永远成立：同一发件地址累计 5 封 AUTO_SEND 后会一直触发回环保护；同主题未结案例的 30 天窗口也一直成立。第 1 周测试建议不设置 POC_NOW，或给每类用例使用不同发件邮箱。If POC_NOW was set at deployment, every AI reply timestamp equals the fixed POC_NOW, so “within the last hour” is always true: after 5 AUTO_SEND replies to the same sender address, mail-loop protection is triggered permanently, and the 30-day window for open cases with the same subject also always applies. For Week 1 testing, leave POC_NOW unset or use a different sender mailbox for each type of case.
  • 第 1 周只有 General 和 Security 两个队列：除 SECURITY 外，所有转人工 / 待审核的邮件（team 为 RESERVATIONS、LOYALTY、GENERAL）都进入 SL-Email-General。Week 1 has only two queues, General and Security: apart from SECURITY, every escalated / pending-review email (team RESERVATIONS, LOYALTY or GENERAL) goes to SL-Email-General.
  • GROUNDING_GATE=true 时，知识库作答的邮件可能因 grounding 自检判为 HUMAN_REVIEW 而不自动发送；信息问答类用例把 AUTO_SEND 与 HUMAN_REVIEW 都视为可接受的处置，重点验证事实、语言、签名（HUMAN_REVIEW 时在 reply_body 草稿中验证）。With GROUNDING_GATE=true, a knowledge-base answer may be judged HUMAN_REVIEW by the grounding self-check and not sent automatically; information Q&A cases accept both AUTO_SEND and HUMAN_REVIEW as dispositions and focus on facts, language and signature (for HUMAN_REVIEW, verify them in the reply_body draft).
